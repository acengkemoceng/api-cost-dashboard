# Changelog

All notable changes to AI API Cost Dashboard are documented here.

## [1.2.0] - 2026-10-01

### Added

- Demo Mode
- Sample OpenRouter analytics
- Sample DeepSeek balance history
- Demo Data indicator
- Responsive analytics interface

### Changed

- Live provider collectors are disabled while Demo Mode is active

## [1.1.0] - 2026-10-01

### Added

- OpenRouter Analytics API support
- Request count
- Total token usage
- Input token usage
- Output token usage
- Reasoning token usage
- Cached token usage
- Average cost per request
- Average cost per 1K tokens
- Top model analytics

## [1.0.0] - 2026-10-01

### Added

- Unified multi-provider dashboard
- Provider registry
- OpenRouter integration
- DeepSeek integration
- SQLite history
- Background snapshot collector
- OpenRouter usage charts
- DeepSeek balance charts
- Responsive dashboard
- Docker deployment
